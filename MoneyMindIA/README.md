# Moneymind – IA Asesoría Financiera

Aplicación web que ofrece asesoría financiera personalizada a partir de preguntas predeterminadas,
permitiendo ingresar movimientos bancarios y metas financieras para generar recomendaciones.

## 🚀 Características principales
- Chat con IA financiera mediante preguntas predeterminadas
- Respuestas generadas mediante IA (DeepSeek API)
- Registro de movimientos bancarios y metas desde una vista dedicada
- Sistema de autenticación con login tradicional y Google Authentication
- Integración con SQL Server y Entity Framework
- Interfaz moderna con SweetAlert y animaciones dinámicas
- Arquitectura MVC

## 🧰 Tecnologías Utilizadas
- ASP.NET MVC
- C#
- JavaScript
- SQL Server
- Entity Framework
- DeepSeek API
- Google Authentication
- SweetAlert
- HTML, CSS
