# Seripelis – Recomendación de Películas

Aplicación web interactiva que recomienda una película según las respuestas del usuario en un formulario dinámico.  
La experiencia se basa en animaciones modernas, formularios atractivos y una interfaz enfocada en la interacción.  
Al finalizar la encuesta, el sistema muestra una película sugerida basada en las elecciones realizadas.

## 🚀 Características principales
- Formulario moderno con animaciones
- Preguntas relacionadas a gustos y preferencias audiovisuales
- Recomendación automática de películas
- Interfaz visual llamativa y dinámica
- Integración con Firebase para almacenamiento de imágenes
- Retroalimentación con SweetAlert
- Arquitectura MVC con Entity Framework

## 🧰 Tecnologías Utilizadas
- ASP.NET MVC
- C#
- SQL Server
- Entity Framework
- JavaScript
- SweetAlert
- Firebase
- HTML, CSS
