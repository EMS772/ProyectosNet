# Chat Bot IA – Asesoría Bancaria sobre Préstamos

Aplicación que ofrece respuestas automáticas relacionadas con asesoría bancaria y financiera
(consultas sobre préstamos, tarjetas, tasas de interés, cuentas bancarias, etc.).  
Si el usuario envía una pregunta fuera del contexto financiero, el bot no responderá.

## 🚀 Características
- Respuestas automáticas basadas en IA (OpenAI API)
- Solo responde preguntas financieras o bancarias
- Validación de token JWT para autorización
- Integración con flujo automatizado mediante n8n Workflow
- Base de datos con PostgreSQL y SQL Server
- Arquitectura basada en POO y Entity Framework

## 🧰 Tecnologías Utilizadas
- C#
- ASP.NET Core API
- PostgreSQL
- SQL Server
- Entity Framework Core
- Workflow n8n
- JWT Authentication
- OpenAI API
