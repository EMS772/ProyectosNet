# Sistema de Visitas – Escritorio

Aplicación de escritorio para gestionar y registrar visitas, permitiendo agendar entradas de usuarios externos con todos sus datos y control interno mediante roles de usuario y administrador.  
Incluye una interfaz para administración donde se pueden agregar nuevos módulos y funcionalidades.

## 🚀 Características principales
- Registro y control de visitantes con datos completos
- Agenda de visitas con fecha y hora
- Roles de acceso: Administrador y Usuario
- Panel administrativo para gestión y ampliación de módulos
- Inicio de sesión seguro
- Gestión local con base de datos SQL Server

## 🧰 Tecnologías Utilizadas
- C#
- Windows Forms
- SQL Server
- Entity Framework
