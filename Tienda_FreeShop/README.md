# Freeshop – Tienda Online (ASP.NET MVC)

Aplicación web tipo e-commerce enfocada en la experiencia del cliente.  
Permite visualizar productos disponibles, realizar compras, ver el carrito, registrar pedidos y consultar el historial de compras.  
Incluye autenticación de usuarios y almacenamiento de imágenes con Firebase.

## 🚀 Características principales
- Vista principal con catálogo de productos
- Filtro de productos por categoría
- Carrito de compras funcional
- Registro y login de usuarios
- Historial de pedidos realizados
- Notificaciones y alertas con SweetAlert
- Carga y visualización de imágenes desde Firebase
- Arquitectura MVC con Entity Framework

## 🧰 Tecnologías Utilizadas
- ASP.NET MVC
- C#
- SQL Server
- Entity Framework
- Firebase Storage
- SweetAlert
- HTML, CSS, JavaScript
